### RL00 — Problem Formulation

Introduction to the formalization of Reinforcement Learning problems, including:

- Markov Decision Processes (MDPs)
- States and actions
- Policies
- Trajectories
- Rewards and returns
- Value functions
- Action-value functions

### RL01 — Dynamic Programming

Implementation of classical Dynamic Programming methods for solving tabular MDPs:

- MDP transition and reward models
- Exact Policy Evaluation
- Iterative Policy Evaluation
- Policy Iteration
- Value Iteration

The implementations are evaluated using the **Cliff Walking** environment.

### RL02 — Prediction and Control

This activity will cover model-free Reinforcement Learning methods, including:

- Monte Carlo methods
- Temporal-Difference Learning
- SARSA
- Q-Learning
