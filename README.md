
# Reinforcement Learning

Repository containing the activities, implementations, experiments, and documentation developed for the **Reinforcement Learning** course at **Universidad del Rosario**.

## About

This repository contains the practical work developed throughout the course, including:

- Reinforcement Learning implementations
- Practical activities
- Computational experiments
- Results and analysis
- Supporting documentation

The objective is to maintain an organized and reproducible record of the work developed during the course.
